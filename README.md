## My workflow

2. Learn it, take handwritten notes.
3. Open that folder's `README.md` → fill in **Key Learnings**, drop screenshots into `assets/`, paste the **handwritten notes link**.
4. Update the row in this table: set status to 🟢, add the date, and link the folder.
5. Commit: `git commit -m "notes: <topic>"`
